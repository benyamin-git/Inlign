## Global constraints

Copied from the approved spec; every task inherits these.

**Identity**

- Product: **Inlign** · package name `inlign` (private) · app id `com.inlign.app` · version `0.1.0`.
- License: MIT (`LICENSE`, author `benyamin-git`, year 2026).
- LAN dev port: **7406** (`strictPort`); `live.sh` log `/tmp/inlign-liveserver.log`, pid `/tmp/inlign-liveserver.pid`.
- Repo: `github.com/benyamin-git/Inlign`, Pages base path `/Inlign/`.

**Platform**

- Installable PWA, fully offline after load, **zero network calls**; no accounts, sync, telemetry, or `eval`.
- Tauri v2 wrappers: Windows NSIS, macOS, Linux AppImage/deb, Android APK; iOS is PWA-only. macOS/Linux artifacts unsigned in v1.
- Modern evergreen browsers + Tauri WebViews.

**Toolchain** (mirror ClyTrade unless noted)

- Node `>=22.12`; TypeScript `^6.0.3`, Vite `^8.3.0`, React `^19.3.0`, Tailwind `^4.3.3`, Dexie `^4.4.6`, zod `^4.6.5`, vitest `^5.0.1`, Playwright `^1.63.0`, ESLint `^10.11.0`, Prettier `^3.9.9`, `vite-plugin-pwa ^1.3.0`, `@tauri-apps/cli ^2.11.5`.
- Engine: **Nerdamer pinned exactly `2.0.0`** behind `CasAdapter`; caret ranges elsewhere.
- Editor: CodeMirror 6 — `@codemirror/state ^6.7.6`, `@codemirror/view ^6.43.14`, `@codemirror/language ^6.13.0`, `@codemirror/commands ^6.11.1`, `@lezer/highlight ^1.2.5`.
- Fonts: `@fontsource-variable/ibm-plex-sans ^5.3.0` (variable), `@fontsource/ibm-plex-mono ^5.3.0` (static).
- Markdown rendering: `react-markdown ^10.1.0`. Icons: `lucide-react`.
- No React Router: single-screen app; sheets are state-driven.

**Engine behavior (contracts)**

- `identifier = expr` → definition/claim; other `lhs = rhs` → equation; bare `expr` → result; unparsable line → prose; `#`-prefixed always prose.
- Global solving regardless of line order; symbolic first, bounded numeric fallback; never a guessed number.
- Claim tolerance respects written precision (half-unit of last written digit; integers ±0.5); `toleranceOverride` is a relative tolerance.
- Duplicates: first definition authoritative, later differing redefinition flagged with first RHS as the fix; identical RHS silently deduped.
- Multiple real solutions inline, up to 4 plus a count; complex out of scope. Unresolved symbols show symbolic form.
- `%` = percent literal; `mod(a, b)` = modulo; radians default, degrees setting.
- Number display: exact rational when short, else `precision` significant digits (default 12), trailing zeros trimmed.
- Results are virtual annotations; only click-to-fix (and normal typing) mutates text.

**Performance & quality**

- Solve debounce `SOLVE_DEBOUNCE_MS = 200`; solving in a Web Worker; stale responses dropped by version; smooth to ~500 lines.
- Gates after every task: `npm run typecheck`, `npm run lint`, `npm test`; before phase ends also `npm run build`.
- Tests: table-driven engine goldens, component tests (Testing Library), `fake-indexeddb` data tests, Playwright e2e + screenshots.
- House rules in `AGENTS.md`: `src/engine/**` is pure and protected (no React/DOM/Dexie/i18n imports, no change without owner permission); UI uses semantic tokens only; the twelve bans and accessibility floor are hard rules; strings live in `src/i18n`.

**Settings defaults** — `precision: 12`, `toleranceOverride: null`, `angleMode: 'radians'`, `theme: 'system'`, `accent: 'blue'`.

**Identity shortcuts** — `Mod+N` new notebook, `Mod+K` switcher, `Mod+E` export, `Mod+,` settings.

## Dependencies / ordering

- Phases run in order; inside a phase, tasks are sequential except where noted.
- T10–T12 (data) and T5–T9 (engine) are independent of the UI and of each other; either phase can proceed first, but T14 needs T9, T4, T13.
- T13 (i18n seam) must exist before user-facing strings are written in T16–T18 (strings only, no behavior dependence).
- Distribution tasks (T20–T24) depend on a feature-complete app; T20 (PWA) must precede T21/T22 so native builds package the final web bundle.
- The engine (T5–T9) is the critical path: it is the product's core value and the highest-risk work.

## Risks + rollback

| Risk                                              | Mitigation                                                                     | Rollback                                                                    |
| ------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Nerdamer 2.x API gaps during T6–T7                | Adapter isolates it; golden tests document behavior; exact pin                 | Swap adapter internals to nerdamer-prime/1.x; engine API unchanged          |
| Global nonlinear solving limits                   | Bounded numeric fallback; unresolved markers; engine-limits doc                | Fall back to ordered propagation per statement without changing annotations |
| Worker + CM6 decoration plumbing                  | Tiny protocol, engine-first build order, handler unit tests                    | Run `solveDocument` on the main thread behind the same protocol             |
| Tauri/Android CI friction (SDK/NDK, unsigned mac) | Documented toolchains; artifacts unsigned by design (A6); PWA always available | Ship web/PWA first; native tasks can slip independently                     |
| Playwright flakiness                              | Deterministic seeded data, demo-only screenshots, preview server               | Mark flaky flow as manual until stabilized (no feature blocked)             |

Plan-wide rollback: nothing ships to a server until T23; Pages deploys are revertible to any commit; user data lives on-device with export/backup available at all times. The repo only grows docs and code commits — no migration or data-loss surface exists before v0.1.0.
